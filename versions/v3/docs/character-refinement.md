# 人物第二轮精修 · 2026-10-08

本轮按最新“浪漫文艺 / 科学家”方向修改，替代上一版“文艺 / 赛博护目镜”的造型。两侧仍使用 Humanities / Technology 内容身份。

## 外观与结构

- 共享面部、身体及 15 骨骨架；发型现在属于服装变体，可以单独切换。
- 文艺版：侧分雕刻发束、两侧卷发、半扎长发、细缎带与玫瑰饰、珍珠耳饰；奶油色花瓣裙与叶片纹样。
- 科学家版：侧梳盘发、发簪、细框圆眼镜；灰蓝网球服、象牙色翻领、拉链、缝线口袋和轨道形胸针。保留轻量运动服，没有书、电脑或额外手持道具。
- 手臂与腿改为连续网格，在肘膝附近混合权重，修复原先球体/圆柱拼接处的明显边界。
- 球拍：椭圆拍框、开口 Y 形拍喉、独立纵横拍线、缠绕握柄、贴合握柄的手指；双服装分别为玫瑰色与钛银色。第一人称近景球拍也更新为相同结构语言。

## 动作

- 新增 Hand.L / Hand.R / Foot.L / Foot.R，骨架由 11 骨增至 15 骨。
- Idle / Ready / Run / Shuffle / Swing 共五段动画；新增侧向垫步，横移和后退时保持面向来球。
- 跑步加入踝部滚动，挥拍加入独立手腕动作。动作混合时各段保留独立时间，避免切换瞬间步态重置。
- 保持挥拍甜区固定在局部 [0.75, 1.18, 0.47]；导出 Racket_Contact 空节点用于测试。Swing 中点与回球接触时刻同步。
- 到场转向与复位转向平滑插值；完整随挥结束后才复位。沿用上一版较快的回合节奏。

## 验证

- GLB 1,283,760 bytes，全部服装合计 30,184 三角面，无外部贴图，低于 3 MB 目标。
- Blender 渲染检查两套服装以及 Run、Shuffle、Swing 准备/接触关键帧。
- TypeScript / Vite 构建通过；16 项测试通过，包括独立骨架、五段动画、腕踝节点，以及实际 GLB 接触点位置与挥拍偏移。
- 浏览器验证两侧人物加载与完整击球回合。模型仍为 stylized 基础运动动画，不是全身实时 IK 或动作捕捉。
