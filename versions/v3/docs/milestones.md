# 里程碑与当前验收标准

以下以用户最新要求为准：默认只有云端球场；自由方向与蓄力击球；回合结束顺序循环内容；人物按球路跑位。早期“固定轨迹对应项目”“先选卡片”“不需要跑位”约定已替换。

| 阶段 | 状态 | 当前验收 |
|---|---|---|
| M1 程序化球场 | 已实现 | 白天、粉紫内场、浅蓝外围、云层、球网、全景相机、旋转平移缩放与复位 |
| M2 Rally | 已实现 | 第一人称与全景切换、轻量球路、取消与连续回合 |
| M3 Switch Sides | 已实现 | 两种身份、服装、视角、内容与 URL 同步；人物始终隔网相对 |
| M4 内容与自由击球 | 已实现 | 松开位置决定落点；按住时长决定力度；跑位接球；内容按数组顺序循环；可直接阅读 |
| M5 Blender Lulu | 已实现 | 同身体骨架两服装；Idle / Ready / Run / Swing；可编辑 blend；GLB 替换；两侧与回合验证 |
| M6 完善与部署 | 本地精修已实现；发布验收待完成 | 已完成裁判席/休息区/天空、文艺与赛博人物、快节奏与动作衔接；待移动真机、性能基准、无障碍完整验收与部署 |

M5 交付：`assets/blender/lulu.blend`、建模脚本与预览；`public/models/lulu.glb`；网页动画控制与加载回退；模型测试。详细结果见 `m5-verification.md`。
