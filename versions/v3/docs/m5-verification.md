# M5 验收 · 2026-10-08

- Blender 5.2 生成并保存可编辑工程。模型 450,228 bytes（约 440 KiB），全部服装合计 9,080 三角面，低于 3 MB 目标。
- 一个 Body、Humanities 与 Technology 两套衣服、11 骨共享骨架。没有书、电脑或其他手持道具；只持球拍。
- Idle / Ready 各 2 秒；Run / Swing 各 1 秒，24 fps 烘焙。所有动作在 GLB 内实际存在，可由 Three.js 解析并独立播放。
- 身高约 2.1 场景单位，脚底原点、导出 Y-up / +Z 正面。中性球拍甜区对应身体局部坐标 [0.75, 1.18, 0.47]；Swing 中点回到此接触姿势。
- 网页接入独立 SkeletonUtils 克隆、服装可见性切换、按回合进度播放与定向跑位。加载期间和失败时保留程序化回退；不影响球场和内容。
- 浏览器验证 Technology / Humanities 换装、蓄力击球、人物移向侧方接球、回合完成卡片和复位。Blender 渲染检查静态造型及动作关键帧。
- 模型测试验证四动画、三个模型组、骨骼、尺度、体积与独立克隆；原有方向/力度/球路/状态测试保留。

## 边界

这是 stylized 基础动作，不是动作捕捉或布料模拟。极端网前与边线位置的脚步、急转和服装细节仍可在 M6 精修。手机仅已有响应式设计，M5 未做触屏真机验收。Vite 仍提示 Three.js 分包较大，留待 M6 性能优化；未部署上线。
