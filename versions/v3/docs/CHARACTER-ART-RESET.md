## 审美诊断（设计判断，不是作者原话）

### 旧 Lulu 为什么仍像拼装玩偶
- 脸部主要是一颗球加两只小眼、鼻子和嘴；缺少额头—颧部—下颌的形体关系，表情显得空。
- 头发的多束光亮形体与布衣的简化程度不同，视觉上像塑料片覆盖头部。
- 球形肩部与短躯干、细长下肢、厚鞋组合没有统一比例语言。
- 蝴蝶结、花朵、叶片、眼镜、领片和胸针承担了过多身份表达，基础造型不成立时会更杂。
- 大部分检查在近景里添加小细节，没有先确认黑色剪影、正侧三视图及网页小尺寸是否好看。

### 从成熟资源学什么
- **Kenney：少而明确。** 发际线、眉眼、衣服大色块就能建立角色；不必把每个面部细节做成凸起小球。其统一 UV 皮肤与完整网格值得研究。
- **Quaternius：结构优先。** 官方展示中的脸部转折、肩颈和骨盆衔接更有身体感；适合作为成年运动员人体/面部结构参考。不能照搬它的超级英雄肌肉比例。
- **KayKit：轮廓优先。** 帽子、头发、肩线、衣摆形成不同的大轮廓；小装饰服从主体。可以学它的层次，不采用厚重盔甲或过度幼态比例。

## 采用的方向

轻盈、成年、风格化的女性网球角色；同一张脸、同一套身体与骨架。保留 Lulu 身份，不用成人写实皮肤，也不沿用现有“球头＋圆肩＋细四肢”的程序化拼装方式。

1. **人体与头部灰模**：先统一约 5.5–6 头身的设计草案，肩颈、肘膝、手掌和脚部形成连续造型；在灰模阶段比较正面、侧面、3/4。该比例只是起点，最终以画面为准。
2. **脸与头发**：先做眼眶/眉眼、颧部、下颌的简化平面；尝试少量面部贴图，不堆小球。头发先做清楚的整体体块，再决定分束。
3. **网球服**：同身体制作轻量上衣与运动裙/短裤。Verse 用柔和侧分或低束发、奶油色、一个植物标记；Code 用利落束发、蓝灰色、一个几何标记。去掉互相竞争的装饰。
4. **动作**：握拍、预备、侧跨步、挥拍分别验证；自然屈膝和重心优先于动作数量。双角色始终右手持拍。
5. **整合**：只在角色近景和球场实际尺寸都合格后替换在线模型。绑定迁移、接球锚点和动作测试不能省略。

## 新的验收门槛

- 同灯光、同机位展示当前版与候选版；不能靠更漂亮的渲染背景掩盖模型问题。
- 无花纹灰模、黑色剪影、全彩模型都要成立。
- 缩到 80–120 像素仍分得清头、手臂、球拍和身体，不依赖微小饰件辨识。
- 脸部近景没有空洞凝视、头皮穿插、悬浮眉眼；发束没有塑料条堆叠感。
- 不因资源可下载就直接上线；记录具体作者、包版本与许可。需要购买的源文件不擅自购买。
