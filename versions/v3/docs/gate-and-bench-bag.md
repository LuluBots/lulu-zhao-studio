# Half-open gate and bench bag trial

About uses an original sage-green court gate with ivory diamond mesh. Gate starts partly open and opens a little further on mesh hover; reduced motion snaps to the target. Existing About navigation and scoreboard occlusion remain in place. No portrait or profile screen.

Tennis bag model separated from cloud perch, scaled to 0.38 and placed on the near courtside bench seat. Clicking it opens a compact native modal with Camera, Notebook, Headphones. No persistent label/icon; a transparent keyboard target provides access. Escape, close button and backdrop dismiss it.

Content sources: the saved v1 worker About and Photography content; photo copied from https://v1.luluzhao.me/photos/puerto-rico-04.jpg. Music preferences come from the user's current conversation. Photography and writing links go to existing v1 pages. The music section points to the physical radio and does not add another player.

Validation: production build; browser checked three hobby sections, photo loading, Escape/close, About navigation, day/night scene. No deployment.
