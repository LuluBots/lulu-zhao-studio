# M6 · 本地视觉与运动精修（2026-10-08）

> 后续人物已进一步改为浪漫文艺 / 科学家造型，新增手腕、脚踝、连续关节和垫步动画。当前模型数据与验证见 `character-refinement.md`；下方记录为本轮早期版本。

## 场景

- `Courtside.tsx`：带遮阳顶与梯子的裁判席、木质休息平台、双长椅、条纹遮阳伞、毛巾、小桌水瓶、橄榄树与花盆。保持球场中央无障碍。
- `Atmosphere.tsx`：方向渐变天空、柔和日光光晕、高空薄云、距离雾。修复天空球被相机远裁面截断和伞面缺少法线的问题。
- `Clouds.tsx`：近景与远景云层分别实例化为两组，降低重复云朵的绘制开销。远云用距离雾过渡，不用叠加透明球造成的轮廓伪影。
- 仍是白天、低饱和云端网球场，无常驻文字、工具栏或复杂建筑。

## 人物

- Humanities：奶油色花瓣裙摆、玫瑰发饰、缎带、领结、叶片刺绣和粉色球拍。
- Technology：墨蓝不对称短袖、单侧电子护目镜与耳机、护腕、单腿机能袜、青色线路和球拍光圈。科技感集中在人物，不把整个天空变成夜景霓虹。
- 仍共用同一身体、11 骨骨架，只持球拍。GLB 686,604 bytes，含两套服装合计 14,336 三角面，无外部贴图。

## 节奏与动作

- 完整回合由约 3.4–5.5 秒缩短至 1.95–2.85 秒；蓄力依旧影响速度与弧线。
- 入场镜头由 1.05 秒改为 0.72 秒；换边镜头与人物朝向一起缩短为 1.05 秒。
- 步频按实际移动距离推进，动作间短暂混合；接触区间锁定 Swing，保证球拍甜区与回球点一致。
- 回球后按有限速度复位，不再在回合末尾快速滑回。下一次移动从人物当前位置开始。
- 修复 React StrictMode 重放 effect 时动画动作被停止后未重新激活的问题。
- 跑步减少上下弹跳，挥拍增加准备和随挥幅度；近景球拍缩小 20%，网球半径由 .20 调整为 .13，同时同步落地高度。
