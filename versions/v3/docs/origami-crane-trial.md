# About origami crane trial

Source: PRINCE.JACK, Crane_Origami (CC BY 4.0), https://sketchfab.com/3d-models/crane-origami-f4b318fc66564118920260b42730990f

Uses the downloaded original GLB geometry, not procedural replacement geometry. Metallic material replaced with rough ivory paper. Existing About cloud and navigation retained; small hover lift, disabled with reduced motion. No continuous idle animation. Credits included in public/credits.html. Gate component retained as an unused reversible trial.

## Flying revision
Crane enlarged from 3.6 to 5.1 world units, cloud removed, and original wing vertices animated around their fold axis. Body remains intact. Research and Writing drift within bounded paths; balloon has a smooth lobed envelope, seams and basket weave with slow vertical motion. Routes remain outside court bounds; screen-space overlap with the court and scoreboards suppresses the relevant visitor. Reduced motion uses static poses.

## Quiet interaction revision
All four destinations use fixed perimeter anchors. Models play a local 1.2-second animation only when clicked; text labels open sections directly. Crane lowered to the right side. Writing cloud removed, retaining the existing bicycle/bookshop model. Bag Headphones replaced by Hobbies (sports and learning guitar); Camera links to https://www.instagram.com/lulu.coco25/.
