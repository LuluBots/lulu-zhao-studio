# Grand Slam with Lulu — 视觉重构与验收计划

2026-10-22。依据当前网站代码、日夜截图，以及 Jesse Zhou 网站的实际场景和公开源码审查。目标是具有明确美术方向的网球微缩世界，不复制拉面店资产或霓虹主题。

## 问题诊断

1. **没有主次**：四个空中标牌亮度与面积接近，云朵又不断出现，视线被拉向外围。参考场景把导航、物件、灯光集中到同一个主体，外围留白。
2. **天空渐变在实际镜头下失效**：原天空球按方向着色，正交俯视采样范围过窄；有渐变代码不等于画面里看得到层次。
3. **云朵像散落的实体模型**：固定不透明度、每 160ms 可生成一朵、最多 12 朵；缺少承托层与远景层的区分。
4. **人物站位违背网球语义**：旧“网前迎接”要求残留，准备位置也停在场内。新要求取代旧要求：两名球员在相反底线外、对角半区准备。
5. **模型精度不统一**：球拍、服装、椅架、伞顶、平台边缘的完成度不同。材质贴图无法替代合理轮廓、连接结构、比例和接地。
6. **反馈缺少叙事**：彩蛋只有文字高亮，尚未形成与四条个人故事相关、轻量且克制的局部反馈。
7. **光照尚未统一**：目前是真实的地面间接光烘焙加实时家具照明，不能称为全场景逐对象烘焙。

## A. 构图、天空与比赛语义（本轮）

- 两人准备坐标：访客 (-1.5, 0, 9.35)，对手 (1.5, 0, -9.35)；底线为 z=±8.7。初始展示、角色选择、回位与交换都使用相同语义；可自由移动范围保留。
- 天空：白天蓝→雾蓝→暖杏色；夜间深靛蓝→灰紫→低饱和暮色。渐变在正交和 Rally 镜头中均可见，保留主体对比。
- 云层：集中于球场底部，远处少量大云；指针薄云至少相隔 650ms 和 135px，池容量 4，每朵固定随机透明度 0.24–0.49 和尺寸。边缘渐淡，不逐帧闪动，不遮计分牌。
- 验收：日夜全景、两个角色进入 Rally、回位、换边截图；底线测试、原有轨迹/接球/镜头回归测试通过。

## B. 主体构图与统一模型（下一阶段，尚未完成）

- 先固定三张构图：桌面全景、移动端全景、Rally。四个入口仍保留，但统一航线高度、标牌比例和低对比底色；悬停才强调选中项。
- Blender 逐件精修：平台做薄层结构与有尺度的倒角；球网有张力和绑带；球拍完善拍喉、握把、缠带及弦网；座椅采用一致木条间距与金属连接；伞顶统一布片弧度、缝线、伞骨。
- Verse：有辨识度的发束、轻盈衣摆、奶油色与少量植物刺绣。Code：利落发型、柔和深蓝服装、少量几何接缝。两者共用身体骨架，动作不靠整体滑移。
- 验收：每个模型提供同角度的改前/改后近景；在首页缩略尺度仍能辨认角色，在最大缩放下没有穿插、悬空或明显拼接。

## C. 局部彩蛋与交互节奏（尚未完成）

- 四条已有个人彩蛋保留：邻近球场、一起打球、Djokovic、其他运动。
- 每项只设计一种局部反馈：文字/图案描边、短促网球弧线、克制星形高光或小轮印；不弹气泡、不自动循环、不引入虚构经历。
- 悬停预告可交互、点击给明确结果、离开恢复；键盘聚焦提供等价状态，减少动态效果偏好下静态呈现。
- 验收：无需说明即可识别交互，单项反馈不遮球/人/导航，同屏只突出一个交互点。

## D. 全场景光照与最终验收（尚未完成）

- 为静态家具分别展开 UV，日夜各自烘焙间接光与接触细节；动态人物保留实时光照，不能烘入固定影子。
- 木、织物、橡胶、皮肤各自使用匹配尺度的粗糙度和微细法线，避免统一噪声。
- 交付日夜与桌面/移动端对照，检查模型接缝、文字清晰度、遮挡、输入响应、资源体积及加载过程。
- 每阶段完成后更新此表；不能以“增加了纹理/灯光参数”代替实际画面验收。
